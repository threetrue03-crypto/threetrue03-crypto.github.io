# MMA-Former: 3D MRI의 적응형 PNI 예측을 위한 다중 윈도우 Mixture-of-Head 어텐션 트랜스포머

> **원문 제목:** MMA-Former: Multi-Window Mixture-of-Head Attention Transformer for Adaptive PNI Prediction in 3D MRI  
> **저자:** Youngung Han, Induk Um, Kyeonghun Kim, Junga Kim, Hyunsu Go, Jaewon Jung, Woo Kyoung Jeong, Won Jae Lee, Pa Hong, Ken Ying-Kai Liao, Hyuk-Jae Lee, Nam-Joon Kim  
> **arXiv:** 2607.10988v1, 2026년 7월 13일  
> **용어:** Perineural invasion(PNI)은 **신경주위 침범**으로 번역하였다.

## 초록

신경주위 침범(perineural invasion, PNI)은 담관암의 중요한 예후 인자이다. 3D MRI에서 PNI를 비침습적으로 예측하려면 미세한 세부 정보와 전역 문맥을 모두 효율적으로 포착해야 하므로 난도가 높다.

본 연구에서는 병렬 다중 스케일 특징 추출을 위한 Coarse-Fine Transformer(CFT) 구조를 포함하는 새로운 종단간 3D 모델인 **Multi-window Mixture-of-Head Attention Transformer(MMA-Former)**를 제안한다. 여기에 새로운 **Window-Specific Mixture-of-Head attention(WS-MoH)** 기법을 결합한다.

표준 Multi-Head Self-Attention(MSA)과 달리 WS-MoH는 각 3D 윈도우의 대표 표현을 생성하고, 윈도우 전체를 특화 어텐션 헤드 또는 공통 어텐션 헤드로 동적으로 라우팅한다. 이를 통해 각 윈도우의 국소 문맥에 맞는 공간 적응형 특징 추출이 가능하며, 파라미터 수를 늘리지 않고도 헤드 전문성을 높이고 중복을 줄인다.

T1 강조 MRI 168건으로 구성된 후향적 데이터셋에서 MMA-Former는 AUC 0.752를 달성하였다. 이는 가장 좋은 CNN 기준 모델의 AUC 0.708과 트랜스포머 기준 모델의 AUC 0.681보다 높은 성능이다.

**색인어:** 비전 트랜스포머, Mixture-of-Head 어텐션, 적응형 특징 추출, 윈도우 단위 라우팅

## 1. 서론

PNI는 암세포가 신경초를 따라 침윤하는 현상으로, 담관암의 중요한 전이 경로이다. PNI가 존재하면 재발 위험이 크게 증가하고 생존율이 낮아지며 수술 계획도 달라진다[1-3]. 따라서 맞춤 치료를 위해 수술 전에 PNI를 정확히 식별하는 것이 중요하다.

그러나 PNI의 MRI 소견은 매우 미세하므로 비침습적 예측이 어렵다[4, 5]. 기존 PNI 연구는 대개 수백 명 이하의 소규모 코호트에 기반하여 클래스 불균형 문제도 빈번하다[2, 6].

방법론적으로 기존 접근은 라디오믹스 특징에 의존하는 경우가 많지만[7], 이러한 특징은 복잡한 3D 공간 패턴을 충분히 포착하지 못할 수 있다. 종단간 딥러닝은 대안이 될 수 있으나, 표준 구조에도 한계가 있다. CNN[8, 9]은 장거리 의존성 모델링에 약하며, Vision Transformer(ViT)[10, 11]와 3D 변형 모델[12]은 3D MRI에서 계산 비용이 지나치게 커질 수 있다.

Swin Transformer[13] 같은 계층적 구조는 국소 윈도우 내부에서 어텐션을 계산하여 효율을 높인다. 이를 확장한 MViT[14], Focal Transformer[15] 등의 병렬 다중 스케일 윈도우 구조는 서로 다른 스케일의 특징을 동시에 포착한다. 하지만 이들 모델의 표준 MSA는 입력 문맥과 무관하게 모든 헤드를 동일하게 사용하므로 적응형 특징 선택이 제한되고 어텐션 헤드 사이에 중복이 발생한다[16-18].

Mixture-of-Experts(MoE)[19, 20]에서 영감을 받은 Mixture-of-Head attention(MoH)[16]은 어텐션 헤드를 전문가로 간주하고, 라우터가 입력마다 특화 헤드 일부를 동적으로 선택한다. 이는 헤드 전문성과 효율을 향상시키지만, 일반적인 MoH는 토큰 단위로 라우팅하므로 3D 데이터에서는 여전히 계산량이 크다.

본 연구는 다중 스케일 처리와 새로운 MoH 변형을 결합한 적응형 3D 구조인 MMA-Former를 제안한다. CFT는 미세 윈도우와 거친 윈도우를 병렬로 처리하여 다중 스케일 정보를 포착한다. 핵심인 WS-MoH는 각 토큰이 아니라 **윈도우 전체를 하나의 단위로 라우팅**한다. 따라서 서로 다른 공간 영역이 서로 다른 어텐션 헤드 조합을 효율적으로 사용한다.

주요 기여는 다음과 같다.

- PNI 예측을 위해 병렬 다중 스케일 특징을 추출하는 CFT 기반 3D 종단간 구조 MMA-Former를 제안한다.
- 각 윈도우의 공간 문맥에 따라 전체 윈도우를 라우팅하는 새로운 WS-MoH를 제안한다.
- 서로 다른 인코더 단계의 계층적 특징을 융합하는 Xpace 블록을 도입한다.

## 2. 방법론

### 2.1. 데이터셋과 전처리

삼성서울병원에서 약 10년에 걸쳐 여러 MRI 스캐너로 촬영한 익명화 T1 강조 조영증강 MRI의 간담도기 영상을 사용하였다. 영상은 NIfTI 형식으로 제공되었으며, 간과 종양의 정답 분할 마스크를 포함하였다.

품질 관리 후 최종 분석 코호트는 담관암 환자 168명으로 구성되었다. 수술 후 조직병리검사로 PNI 여부를 확인했으며, PNI 양성은 67명, 음성은 101명이었다.

종양을 중심으로 $96\times96\times48$ 크기의 체적을 잘라내는 국소화 전략을 적용하였다. 제거 실험의 입력 전략 비교는 이러한 국소화가 필요함을 보여 준다.

### 2.2. MMA-Former 구조

MMA-Former는 계층적 구조를 사용한다. 입력 3D 체적을 패치로 분할하고 선형 임베딩한다. 인코딩 단계 이후 $K$개의 단계가 이어진다. 각 단계는 패치 병합 계층과 특징 추출용 MMA 블록으로 구성된다.

Xpace 블록은 이전 단계의 다운샘플링된 표현과 현재 단계 특징을 결합해 계층적 특징을 융합한다.

### 2.3. MMA 블록: CFT와 WS-MoH

#### 2.3.1. CFT 구조

Coarse-Fine Transformer(CFT)는 서로 다른 윈도우 크기의 병렬 경로를 통해 다중 스케일 정보를 포착한다.

하위 블록 $l$의 입력 특징맵을 $z^{l-1}$이라 하고 계층 정규화를 적용한다. 정규화된 특징 $z'$는 두 경로로 나뉜다.

- Fine 경로 $P_f$: 작은 윈도우 $W_F$를 사용한다. 예시는 $3\times3\times3$이다.
- Coarse 경로 $P_c$: 큰 윈도우 $W_C$를 사용한다. 예시는 $6\times6\times6$이다.

두 경로 모두 WS-MoH를 어텐션 연산으로 사용한다.

```math
A_F=\operatorname{WS\!\text{-}MoH}_{W_F}(z'),
\qquad
A_C=\operatorname{WS\!\text{-}MoH}_{W_C}(z'). \qquad \text{(1)}
```

두 출력을 이어 붙이고 선형 투영으로 융합한 뒤 입력과 잔차 연결로 결합한다.

```math
A_{\mathrm{fused}}=\operatorname{Fusion}(A_F,A_C)+z^{l-1}. \qquad \text{(2)}
```

이후 MLP를 적용한다.

```math
z^l=\operatorname{MLP}\!\left(\operatorname{LN}(A_{\mathrm{fused}})\right)+A_{\mathrm{fused}}. \qquad \text{(3)}
```

다음 블록 $l+1$은 윈도우 간 정보 교환을 위해 shifted window partitioning 기반 SWS-MoH[13]를 사용한다.

#### 2.3.2. WS-MoH

WS-MoH는 표준 MSA를 윈도우별 적응형 MoH로 대체한다. 표준 MSA는 입력 문맥과 관계없이 $h$개의 모든 헤드를 균일하게 활성화한다.

```math
\operatorname{MSA}(X)=\sum_{i=1}^{h}H^i(X)W_O^i. \qquad \text{(4)}
```

MoH[16]는 라우터가 헤드별 가중치 $g_i$를 동적으로 정하도록 한다. 본 연구는 이를 3D 데이터에 효율적으로 적용하기 위해 윈도우 단위로 확장한다.

먼저 윈도우 내부 입력 특징 $X_W$에 표준 쿼리, 키, 값 투영을 적용한다.

```math
Q=X_WW_Q,\qquad K=X_WW_K,\qquad V=X_WW_V. \qquad \text{(5)}
```

핵심은 각 토큰을 별도로 라우팅하지 않는다는 점이다. 윈도우의 특징 $X_W$를 평균 풀링하여 하나의 대표 특징 $X_{\mathrm{rep}}$를 만든다. 라우터는 이 대표 특징을 이용해 전체 윈도우의 라우팅 점수 $g_i$를 계산한다.

선택된 헤드들의 출력을 가중합한 WS-MoH 출력은 다음과 같다.

```math
\operatorname{WS\!\text{-}MoH}(X_W)
=\sum_{i=1}^{h}g_i(X_{\mathrm{rep}})H^i(X_W)W_O^i. \qquad \text{(6)}
```

서로 다른 윈도우는 국소 문맥에 따라 서로 다른 헤드 조합을 활성화하므로 공간 적응형 특징 추출이 가능하다.

본 연구는 2단계 라우팅 전략[16]을 사용한다. 헤드는 다음 두 집합으로 구분한다.

- **Shared Heads $H_S$:** 공통 지식을 포착하며 항상 활성화된다.
- **Routed Heads $H_R$:** 특화 패턴을 처리하며 입력에 따라 일부만 선택된다.

라우터는 $X_{\mathrm{rep}}$에서 routed head의 확률을 계산하고 Top-K 헤드를 선택한다.

```math
P_R=S(W_rX_{\mathrm{rep}}). \qquad \text{(7)}
```

라우팅 점수는 Shared Head와 선택된 Routed Head의 기여를 $\alpha_1$, $\alpha_2$로 조절한다. 여기서 $[\alpha_1,\alpha_2]=S(W_hX_{\mathrm{rep}})$이며 $S(\cdot)$는 softmax이다.

```math
g_i(X_{\mathrm{rep}})=
\begin{cases}
\alpha_1 S(W_sX_{\mathrm{rep}})_i, & i\in H_S,\\
\alpha_2(P_R)_i, & i\in\operatorname{Top\!\text{-}K}(H_R),\\
0, & \text{그 외}.
\end{cases} \qquad \text{(8)}
```

- **W-MSA:** 각 윈도우에서 모든 헤드를 동일하게 활성화한다.
- **WS-MoH:** 윈도우 대표 특징을 입력받은 라우터가 Routed Head 중 Top-K를 선택하고, 항상 활성화되는 Shared Head와 결합한다. 윈도우마다 다른 헤드 조합을 사용할 수 있다.
- **SWS-MoH:** 이동된 윈도우 구성에 WS-MoH를 적용한다. 윈도우 위치가 바뀌면 각 윈도우의 문맥도 달라져 라우터가 다른 헤드 조합을 선택한다.

#### 2.3.3. 부하 균형 손실

라우팅을 사용하는 혼합 모델은 일부 헤드에 입력이 집중되고 나머지 헤드는 충분히 학습되지 않는 불균형이 발생하기 쉽다[19]. 이를 완화하고 모든 Routed Head를 효과적으로 활용하기 위해 부하 균형 손실을 사용한다.

```math
\mathcal{L}_{\mathrm{LB}}=\sum_{i\in H_R}P_i\cdot f_i. \qquad \text{(9)}
```

$P_i$는 $i$번째 헤드의 평균 라우팅 확률이고, $f_i$는 전체 윈도우 중 해당 헤드를 선택한 비율이다.

### 2.4. Xpace 블록

Cross-Spatial Attention(Xpace) 블록은 인코더 단계 사이의 특징을 융합한다. 먼저 이전 단계의 특징을 다운샘플링한다. 이후 다운샘플링된 특징과 현재 단계 특징 사이에서 양방향 교차 어텐션을 수행한다.

두 표현에는 중요한 영역을 강조하기 위한 공간 어텐션을 적용한다. 결과 특징을 채널 차원으로 이어 붙인 뒤 다음 단계에 전달한다.

## 3. 실험 및 결과

### 3.1. 실험 설정

모든 실험은 NVIDIA A100 GPU에서 수행하였다. 168개 사례에 대해 층화 5겹 교차검증을 사용하였다. AdamW[22], 학습률 $8\times10^{-5}$, 배치 크기 4를 사용하였다.

전체 손실은 클래스 불균형을 처리하기 위해 양성 클래스 가중치 1.5를 적용한 weighted binary cross-entropy 손실 $\mathcal{L}_{\mathrm{WCE}}$와, 계수 $\beta=0.01$을 적용한 부하 균형 손실을 결합한다.

```math
\mathcal{L}_{\mathrm{Total}}
=\mathcal{L}_{\mathrm{WCE}}+\beta\mathcal{L}_{\mathrm{LB}}. \qquad \text{(10)}
```

### 3.2. PNI 예측 성능

종양 중심으로 크롭한 3D 영상에 대한 5겹 교차검증 AUC는 다음과 같다.

| 범주 | 3D 모델 | 평균 AUC |
|---|---|---:|
| CNN | ResNet [8] | 0.708 |
| CNN | DenseNet [9] | 0.688 |
| CNN | EfficientNet [21] | 0.673 |
| Transformer | Swin Transformer [13] | 0.681 |
| Transformer | **MMA-Former(CFT + WS-MoH)** | **0.752** |

MMA-Former는 평균 AUC 0.752로 가장 높은 성능을 기록하였다. 가장 좋은 CNN인 ResNet의 0.708과 표준 3D Swin Transformer의 0.681을 모두 상회하였다.

### 3.3. 제거 실험

기본 설정은 종양 중심 크롭, Fine·Coarse 2개 경로의 CFT, Shared Head 2개와 Routed Head Top-K 비율 75%를 사용하는 WS-MoH, Xpace 블록으로 구성된다.

|---|---|---|---:|
| 기준 | MMA-Former 전체 모델 | 크롭 입력, CFT 2경로, WS-MoH($S=2$, Top-K 75%), Xpace | **0.752** |
| 입력 전략 | 크롭하지 않은 입력 | 전체 MRI 체적 사용 | 0.705 |
| 입력 전략 | 종양 중심 크롭 | $96\times96\times48$ 국소 체적 | **0.752** |
| 구성요소 | WS-MoH 제거(CFT+MSA) | 모든 헤드를 활성화하는 표준 MSA | 0.731 |
| 구성요소 | CFT 제거 | 단일 윈도우 경로의 표준 트랜스포머 블록 + WS-MoH | 0.690 |
| 구성요소 | Xpace 제거 | 단계 간 특징을 명시적으로 융합하지 않음 | 0.709 |
| CFT 경로 | Fine 경로만 사용 | 작은 윈도우 단일 경로 | 0.704 |
| CFT 경로 | Coarse 경로만 사용 | 큰 윈도우 단일 경로 | 0.718 |
| CFT 경로 | Fine + Coarse | 병렬 2경로 | **0.752** |
| Shared Head 수 | $S=0$ | Shared Head 없음, Routed Head Top-K 75% | 0.748 |
| Shared Head 수 | $S=1$ | Shared Head 1개 | 0.737 |
| Shared Head 수 | $S=2$ | Shared Head 2개 | **0.752** |
| Shared Head 수 | $S=\mathrm{All}$ | 모든 헤드가 Shared, 라우팅 없음(MSA와 동일) | 0.731 |
| Top-K 비율 | 50% | $S=2$ | 0.743 |
| Top-K 비율 | 75% | $S=2$ | **0.752** |
| Top-K 비율 | 90% | $S=2$ | 0.733 |

#### 입력 국소화의 영향

크롭하지 않은 영상으로 학습하면 AUC가 0.047 감소하였다. 이는 미세한 PNI 단서를 검출하려면 종양 주변 영역으로 입력을 국소화하는 것이 중요함을 보여 준다.

#### 핵심 구성요소의 영향

WS-MoH를 표준 MSA로 대체하면 AUC가 0.021 감소하였다. 이는 윈도우 문맥에 맞게 특징을 선택하는 WS-MoH가 성능 향상에 기여함을 의미한다. CFT를 제거하면 AUC가 0.690으로 감소하였고, Xpace를 제거하면 0.709로 감소하였다.

#### CFT 구성의 영향

Fine 경로만 사용할 때 AUC는 0.704, Coarse 경로만 사용할 때는 0.718이었다. 두 경로를 병렬로 사용한 구성이 0.752로 가장 높았다. 즉 국소 문맥과 넓은 문맥을 함께 모델링하는 것이 단일 스케일 접근보다 효과적이다.

#### Shared Head 수의 영향

Shared Head 2개가 공통 특징 보존과 적응형 전문화 사이에서 가장 좋은 균형을 제공하였다. Routed Head만 사용하면 공통 특징 포착이 부족하고, 모든 헤드를 Shared Head로 사용하면 입력별 특화가 사라진다.

#### Top-K 비율의 영향

Routed Head의 75%를 활성화했을 때 성능이 가장 높았다. 너무 적은 헤드를 사용하면 표현 용량이 부족해지고, 너무 많은 헤드를 사용하면 중복이 다시 증가하는 것으로 해석된다.

### 3.4. 정성적 결과와 시각화

3D Grad-CAM[23]을 이용해 예측에 가장 큰 영향을 준 영역을 시각화하였다. MMA-Former는 종양과 바로 인접한 종양주위 경계에 집중하였다. 이는 PNI 식별에 중요한 영역과 일치한다.

## 4. 논의 및 결론

MMA-Former는 계층적 트랜스포머 안에서 공간 적응형 특징 추출을 구현하는 새로운 3D 의료영상 분석 방법이다. 입력 국소화가 성능에 필수적이라는 결과가 모델의 효과를 뒷받침한다.

핵심 기여는 CFT 내부의 WS-MoH이다. CFT는 서로 다른 윈도우 크기를 통해 다중 스케일 문맥을 제공한다. WS-MoH는 윈도우 단위 적응을 통해 CFT+MSA보다 높은 성능을 보였다. 각 윈도우 대표 표현을 특화 헤드로 동적으로 라우팅함으로써 미묘한 국소 문맥을 포착한다. 이는 모든 헤드를 균일하게 사용하는 MSA와 다르며, 토큰 단위 MoH의 높은 계산 비용도 피한다.

주요 한계는 168개 사례로 구성된 단일 기관 데이터셋이라는 점이다. 표본 수는 관련 PNI 연구와 비슷하지만, 일반화 성능을 확인하려면 다기관 외부 데이터셋에서 검증해야 한다.

결론적으로 MMA-Former는 PNI 예측을 위한 적응형 3D 트랜스포머이다. CFT와 WS-MoH를 결합해 다중 스케일 문맥을 포착하면서 효율적인 공간 적응형 특징 추출을 수행한다. 실험에서 AUC 0.752를 달성하여 기존 3D 백본의 최고 성능 0.708을 상회하였다. 이는 복잡한 3D 의료영상 과제에서 윈도우 단위 적응형 어텐션이 유용함을 보여 준다.
