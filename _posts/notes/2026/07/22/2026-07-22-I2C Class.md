# I2C Class

## I2C Class의 파라미터

I2C Class의 생성자 파라미터를 정리하자면 아래와 같다.

```python
I2C(
    id,
    *,
    scl=None,
    sda=None,
    freq=400_000,
    timeout=50_000
)
```

### id 파라미터
id 파라미터는 I2C가 사용할 블록 번호를 지정한다. RP2040은 0번 블록이 하나밖에 없으므로 0을 입력한다. ESP32에서는 블록이 2개이므로 원하는 블록을 지정하면 된다.

### scl 파라미터
해당 파라미터는 통신하고 싶은 장치의 SCL 핀이 연결되어 있는 GPIO 값을 Pin객체로 생성하여 넘기면 된다. 어렵지 않다. SCK에 대해서 I2C 통신 파트에서 설명했듯이, I2C에는 SCK가 아니라 SCL이고, 제조사에 따라서 SCK로 적혀져 있는 경우가 있다. 이는 SCL로 해석하고 핀을 연결하면 된다.

### sda 파라미터
해당 파라미터는 통신하고 싶은 장치의 SDA 핀이 연결되어 있는 GPIO 값을 Pin객체로 생성하여 넘기면 된다. 이 또한 어렵지 않다.

### freq 파라미터
freq는 SCL 클럭의 주파수를 설정할 수 있다. 장치가 지원하는 클럭의 최대 속도보다 높은 값을 설정하거나, 또한 너무 낮은 값을 설정하게 되면 통신 실패가 발생할 수 있다.

### timeout 파라미터
timeout은 통신의 시작인 START와 끝인 STOP 사이의 시간에 대해 경계선을 정해놓는 것이다. 만약 timeout이 1,000µs(1ms)로 설정했는데 통신 시간이 1,500µs였다면 timeout OSError를 발생시킨다.
timeout 파라미터를 지정할 때, 해당 하드웨어에서 해당 작업이 어느 정도 걸리는지 먼저 분석을 하고 파라미터를 지정해야 할 것이다.
