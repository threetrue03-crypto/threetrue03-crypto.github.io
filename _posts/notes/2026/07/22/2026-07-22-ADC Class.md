# ADC Class

## ADC란
ADC는 `Analog-to-Digital Converter`의 약자이다. 아날로그의 연속적인 값을 컴퓨터가 알아들을 수 있게 디지털 신호로 변환한다는 뜻이다.
아날로그 값인 전압 값은 컴퓨터가 이해하기 매우 어렵다. 그래서 ADC가 특정 순간의 전압을 캐치해서 12비트 숫자로 변환한다. 
MicroPython은 다른 객체와 하드웨어 간의 호환성을 위해 12비트를 16비트로 변환하는 작업을 거친다. 아래 코드를 보면 이해가 된다.

``` C
16bit = 12bit << 4 | 12bit >> 8
```

12비트를 4번 left-shift하여 4비트를 확보한 뒤, 기존 12비트의 상위 비트 4비트를 or연산 하므로써 해당 값을 16비트로 확장할 수 있다.
값을 더 정밀하게 표현한 것이 아니다. 단순히 12비트 값을 16비트로 확장한 것이다. 

예를 들어보자. 1과 2는 12비트로 표현되어 있다.

```
1(10) = 0000 0000 0001(2)
2(10) = 0000 0000 0010(2)
```

해당 값을 16비트로 확장한다고 해보자

```
16(10) = 0000 0000 0001 0000(2)
32(10) = 0000 0000 0010 0000(2)
```

1은 16으로 변하고, 2는 32로 변한다. 하지만 15나 31같은 값은 절대로 표현할 수 없다. 즉 정밀하게 표현되려면 그 사이의 값도 표현될 수 있어야 하지만, 이는 단순히 공간 확장이므로 정밀도가 좋아지지 않는다는 것이다.

## machine.ADC 파라미터와 메서드
MicroPython에서 ADC 생성자는 다음과 같이 정의된다.

```python
ADC(id, *, sample_ns, atten)
```

### id 파라미터
id에는 GPIO 핀의 값을 넣는다. Pin 객체를 직접 넣을 수도 있다. 이는 MicroPython에서 권장하는 방식이다.
필자도 Pin 객체를 넣는 방식을 주로 사용한다. ADC 생성자 내부에서 Pin객체의 내부 설정을 아래와 같이 변경한다.

```
내부 풀업, 풀다운 비활성화, High-Z 상태로 설정
디지털 GPIO 기능 비활성화
```

```python
adc = ADC(Pin(28))
```

### sample_ns 파라미터
`sample_ns`는 ADC 하드웨어가 해당 전압을 12비트로 전환하는 시간을 조절할 수 있는 파라미터다. 아래와 같이 구조도를 그릴 수 있다.

```
센서 전압
   ↓
입력 채널 선택
   ↓
스위치가 닫힘
   ↓
내부 커패시터가 입력 전압까지 충전
   │
   │ 이 시간이 sample_ns
   ↓
스위치가 열림
   ↓
저장된 전압을 12비트 숫자로 변환
```

`sample_ns`는 ADC가 전압을 읽는 주기의 시간이 아니라, 해당 전압을 12비트로 변환할 때까지 그 전압을 충전하는 시간이라고 생각하면 된다. 그래서 해당 파라미터 값이 너무 짧으면 입력 받았던 전압을 못 채우고 12비트로 변환할 수 있다.

### atten 파라미터
`atten`은 attenuation에서 따온 것이다. attenuation는 감쇠를 의미한다. 즉, ADC에 들어오는 전압을 해당 파라미터 비율만큼 감쇠시켜 해당 하드웨어의 전압 제한 범위 안에 포함되게 하여 더 넓은 범위의 전압을 사용할 수 있도록 하는 것이다. RP2040이 아닌 ESP32에서 지원하는 파라미터이고, 해당 상수와 그에 따른 감쇠 정도는 아래와 같다.

```python
ADC.ATTN_0DB
ADC.ATTN_2_5DB
ADC.ATTN_6DB
ADC.ATTN_11DB
```

| 설정               |       감쇠 | 대략적인 측정 범위 |
| ---------------- | -------: | ------------: |
| `ADC.ATTN_0DB`   |    감쇠 없음 |    0.10~0.95V |
| `ADC.ATTN_2_5DB` |    약간 감쇠 |    0.10~1.25V |
| `ADC.ATTN_6DB`   |  더 크게 감쇠 |    0.15~1.75V |
| `ADC.ATTN_11DB`  | 가장 크게 감쇠 |    0.15~2.45V |
